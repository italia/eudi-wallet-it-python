Module contents

Wallet Instance Attestation (WIA) schemas and utilities.

Wallet Instance Attestation is used for client authentication in OAuth 2.0 attestation-based flows. This module is independent of OpenID4VP and can be used by other modules (e.g. OpenID4VCI) that require WIA validation or production.
